## Hi, I'm Vicente 👋

I'm an analyst developer and software architect at Mercedes-Benz, in Madrid. I've been building with Java since 2014: microservices with Spring Boot, DDD and hexagonal architecture. I'm especially into process orchestration with Camunda 8 and BPMN, Vaadin applications and AI-assisted development. I write about what I learn on [Javacadabra](https://javacadabra.vercel.app/) (in Spanish).

🌐 [Website](https://vicente-priego-aviles.github.io/en/) · 📄 [CV](https://vicente-priego-aviles.github.io/en/cv/) · ✍️ [Javacadabra](https://javacadabra.vercel.app/) · ✉️ Contact: coming soon

### Featured projects

- **[meta-harness](https://github.com/vicente-priego-aviles/meta-harness)**: a software factory for Claude Code with project memory in Obsidian, FTD and ASDD work lanes, risk-scoring hooks, clean-context subagent review and measured token savings. [Guide](https://vicente-priego-aviles.github.io/meta-harness/) (Spanish).
- **[arquitectura-microservicios](https://github.com/vicente-priego-aviles/arquitectura-microservicios)**: microservices with Spring Boot from zero to pro, an online shop built chapter by chapter (one branch per chapter): hexagonal DDD, Neo4j and PostgreSQL, RabbitMQ and Kafka, transactional outbox and sagas.
- **[sistema-reservas-viaje](https://github.com/vicente-priego-aviles/sistema-reservas-viaje)**: flight, hotel and car bookings orchestrated with Camunda 8: six hexagonal DDD microservices, parallel bookings and Saga compensations.
- **[camunda-job-workers-guide](https://github.com/vicente-priego-aviles/camunda-job-workers-guide)**: a step-by-step guide to job workers on Camunda 8 Self-Managed with Spring Boot (Spanish).
- **[bartop-arcade](https://github.com/vicente-priego-aviles/bartop-arcade)**: the catalogue of games tested on my bartop arcade (Raspberry Pi 3 + RetroPie), generated from Obsidian with Python.
- **[spring-petclinic-vaadin-flow-vitaminized](https://github.com/vicente-priego-aviles/spring-petclinic-vaadin-flow-vitaminized)**: Spring PetClinic on Vaadin Flow extended with medical records and calendar appointments, built with the Devin agent under my review.
